ปัจจัยที่มีอิทธิพลต่อผลการเรียนของนักเรียน

โครงการสร้างแบบจำลองทางสถิติเพื่อระบุว่าพฤติกรรมการเรียนแบบใดส่งผลต่อผลการเรียนของนักเรียน โดยมีการทดสอบสมมติฐานอย่างครบถ้วนและการตรวจสอบความถูกต้องข้ามแพลตฟอร์มสองแพลตฟอร์ม

โครงงานรายวิชา การวิเคราะห์ข้อมูลและสถิติ 2 (SM340) วิศวกรรมการเงิน มหาวิทยาลัยหอการค้าไทย

วัตถุประสงค์
สร้างแบบจำลองการถดถอยพหุตัวแปรเพื่ออธิบายดัชนีผลสัมฤทธิ์ทางการเรียนจากตัวแปรพฤติกรรมนักเรียนห้าตัวแปร
ตรวจสอบสมมติฐานการถดถอยแบบคลาสสิกทุกข้อก่อนที่จะเชื่อถือผลลัพธ์
เปรียบเทียบวิธีการเลือกตัวแปร (Enter, Forward, Stepwise)
ตรวจสอบว่า SPSS และ Python ให้ผลลัพธ์การประมาณค่าที่สอดคล้องกัน
ข้อมูล
ที่มา: ผลการเรียนของนักเรียน (การถดถอยเชิงเส้นหลายตัวแปร)บน Kaggle
ตัวอย่าง: 8,000 จาก 10,000 รายการ (80%)
ตัวแปรตาม:ดัชนีประสิทธิภาพ
ตัวแปรอิสระ:คะแนนสอบก่อนหน้า, ชั่วโมงเรียน, ชั่วโมงนอนหลับ, แบบฝึกหัดข้อสอบ, กิจกรรมนอกหลักสูตร (ใช่/ไม่ใช่, กำหนดรหัสตัวแปรดัมมี่ โดยกำหนดให้ "ไม่ใช่" = 0)

ตัวแปรทำนายเชิงตัวเลขได้รับการแปลงเป็นค่ามาตรฐาน (Z-score) เพื่อให้สามารถเปรียบเทียบค่าสัมประสิทธิ์ได้โดยตรง

ตัวแปรทำนายทั้งห้าตัวมีนัยสำคัญทางสถิติที่ระดับ p < 0.001 วิธีการคัดเลือกทั้งสามวิธีคงตัวแปรทั้งห้าตัวไว้และสร้างแบบจำลองสุดท้ายที่เหมือนกัน

การตรวจสอบสมมติฐาน:ค่า VIF อยู่ที่ประมาณ 1.00 สำหรับตัวแปรทำนายทุกตัว (ไม่มีภาวะความสัมพันธ์ร่วมหลายตัวแปร) และค่า Durbin-Watson อยู่ที่ 1.989 (ไม่มีภาวะความสัมพันธ์อัตโนมัติ) แผนภาพส่วนเหลือสอดคล้องกับความแปรปรวนคงที่และภาวะปกติ

SPSS เทียบกับ Python:ค่าสัมประสิทธิ์, R² และค่าสถิติ F ตรงกัน ค่าจุดตัดแกน Y แตกต่างกันเล็กน้อย (-0.015 ใน SPSS เทียบกับ -0.018 ใน Python) แต่ไม่มีผลต่อการตีความ

ประเด็นสำคัญ
ความสำคัญทางสถิติเทียบกับความสำคัญในทางปฏิบัติด้วยจำนวนข้อมูล 8,000 ตัวอย่าง แม้แต่ผลกระทบเล็กน้อยก็มีความสำคัญอย่างมีนัยสำคัญทางสถิติ จำนวนชั่วโมงการนอนหลับมีค่า p < 0.001 แต่มีค่า Beta เพียง 0.042 ดังนั้นจึงมีความสำคัญทางสถิติ แต่แทบไม่มีผลในทางปฏิบัติ
ความเหมาะสมของแบบจำลองแบบจำลองนี้มีค่า R² = 0.989 ซึ่งสูงกว่าข้อมูลจริงทั่วไปมาก เนื่องจากชุดข้อมูล Kaggle ดูเหมือนจะเป็นข้อมูลสังเคราะห์ โดยเป้าหมายส่วนใหญ่สร้างขึ้นจากตัวแปรทำนาย คุณค่าของโครงการนี้อยู่ที่ขั้นตอนการทดสอบ ไม่ใช่ความเหมาะสมของแบบจำลอง
